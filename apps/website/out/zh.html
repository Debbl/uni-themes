    best-themes

    React 应用的主题切换——零闪烁、React 19 安全,在 Next.js、React Router、TanStack Start 和 Vite 中行为一致。

    pnpm add best-themes
    快速开始GitHub

    零闪烁(FOUC)

    同步内联脚本在首次绘制前完成主题解析——对所有框架生效,而不只是 Next.js。

    没有 React 19 警告

    脚本由 server layout 渲染,从不经过客户端组件,路由重挂载不可能触发 "script tag while rendering" 错误。

    服务端读取

    Cookie 模式让 loader、服务端组件和 server function 都能读到主题——Next.js 用 getTheme(),其他框架用 getThemeFromRequest()。

    框架无关内核

    纯 DOM store 加 30 行 useSyncExternalStore 绑定。Next.js、React Router、TanStack Start 和 Vite 以子路径入口提供。
